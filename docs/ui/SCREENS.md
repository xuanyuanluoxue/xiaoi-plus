## 1. 首页 Home

**目的**：一屏回答“哪里不对、下一步点哪”。不做配置。

**区块顺序**

1. **状态总览**：四维徽章、Hero 标题/副行、最近上报、主按钮。
2. **快捷条**：校验模型 / 切换模型（只导航）/ 超级岛。
3. **待处理**：最多 3 条 issue；0 条显示“一切正常”。
4. **双域入口**：小爱卡、接入卡、能力清单文字入口。
5. **运行概况**：今日三方/官方、8771/8770 端口与绑定；问题 ≥2 时默认折叠。
6. **最近活动**：最近 3 条语义事件；查看全部 → Logs。

**数据**

```text
StateModel.resolveConfig / resolveApplied / resolveRuntime
StatusCache.probe（D2）
BridgeStatus.get()
AgentRuntime.snapshot()
PermissionProbe
IssueResolver
ActivityFeed.last(3)
BridgeClient.stats(port, token, 1)
```

**状态**：未配置、已暂停、校验中、端点可用但运行未确认、已确认、端点错误、小爱未连接、8770 未启动、配置损坏、权限缺失。每种都要有 CTA；不能只换颜色。

**待处理规则**：MCP 关闭（`mcpEnabled=false`）时不提示令牌/通道；D3 等待/超时与 8770 故障的 CTA 指向 `Bridge`；D4 不一致指向 `Xiaoai`。

**禁止**：输入框、开关、保存、provider/model 选择、token/LAN/主题/备份。

**验收**

- [ ] 只有 D4 `IN_USE` 显示“已确认”。
- [ ] 统计离线显示“—”，不显示 0。
- [ ] 8771/8770 分开；小爱未运行不把 8770 判死。
- [ ] 待处理 0 条不显示空卡。
- [ ] 快捷条只有一个校验入口；执行中禁用。
- [ ] 首屏无配置控件。

## 2. 小爱 Xiaoai

**目的**：回答“小爱现在用什么、是否在生效、下一步怎么变强”。

**区块**

1. **状态卡**：Hero + 主开关“启用第三方模型”（即时保存）。
2. **当前模型卡**：服务商/模型/端点 host/密钥是否设置；“管理模型”。
3. **运行态卡**：D3/D4、运行模型 vs 文件模型、最后上报；“重新通知”。
4. **增强能力（规划中）**：系统提示词、工具注入、技能包、记忆、语音与路由；只读行，无开关。
5. **诊断入口**：最近错误 1 行 → Logs。

**状态**：未配置、配置损坏（开关禁用）、小爱未连接、超时、运行态不一致。

**验收**

- [ ] 主开关即时保存；失败回滚 + Snackbar。
- [ ] 关闭文案“配置全部保留”。
- [ ] 5 个增强项只显示“规划中”，不可点击出假功能。

## 3. 模型与服务商 Model

**目的**：0.14 唯一可编辑的模型表单。

**区块**：服务商 chips + 管理；模型 chips + 添加；端点；密钥（掩码）；校验/保存/取消。

**校验**：URL `http(s)://`；模型 ID 非空；密钥非空才可启用；同名去重；删除当前项自动切换。

**状态**：无服务商、无模型、URL 非法、密钥空、保存失败、文件冲突、配置只读。

**保存**：显式保存；失败保留草稿；成功后 `pop()` + Snackbar “已保存，等待小爱应用”。

**验收**

- [ ] 校验只更新 D2，不改 D4。
- [ ] 删除服务商确认说明连带删除模型/密钥。
- [ ] 配置损坏时输入禁用、保存阻止。

## 4. 接入 Access

**目的**：回答“谁可以连进来、连的是哪个通道、安不安全”。

**区块**

1. **通道状态**：8771 与 8770 各一行：运行中/未开启/等待小爱/启动失败；端口/绑定/工具数。
2. **令牌与安全**：是否设置、强度、8771 LAN、8770 LAN、实际绑定。
3. **连接信息**：URL（LAN/loopback + adb forward）、复制连接信息、复制 Skill。
4. **能力与工具**：5 动作 + 8 + 6 工具；→ Capabilities。
5. **审计/确认（占位）**：0.15 提供。
6. **停用全部**：底部危险文字按钮。

**事实约束**：8770 没有独立开关；跟随 `mcpEnabled + token`；LAN 由 `agentLan` 独立控制。

**验收**

- [ ] 8771/8770 状态分开；小爱未运行不影响 8770 判断。
- [ ] 弱令牌 + LAN 显示“已回退仅本机”。
- [ ] 复制提示“含令牌，勿外传”。
- [ ] 停用全部列出四项影响；执行后首页/接入同步。

## 5. 端口与服务 Bridge（只读）

**内容**：8771（端口/绑定/最后上报/已应用 rev/工具数/leader）；8770（端口/绑定/启动时间/最后错误/动作数/前台通知）；复制 URL、重启 8770、查看日志。

**状态**：8771 等待/超时；8770 未开启/启动失败；分开显示。

## 6. 令牌与局域网 Token

**内容**：令牌掩码/显示/生成/复制；8771 LAN；8770 LAN；强度提示；保存/取消。

**确认文案**：

- “同一 Wi-Fi 下的设备都能访问 MCP 接口。公共 Wi-Fi / 公司网络建议保持关闭。”
- “局域网必须使用 32 位十六进制令牌；不足 32 位会自动回退仅本机。”
- “生成新令牌会让旧 MCP 客户端立即 401。”

**验收**

- [ ] 保存后 8770 重新绑定；8771 由控制面 reload。
- [ ] 弱令牌不显示“局域网已开启”，显示实际绑定。

## 9. 我的 Me

**区块**

1. **本机与版本**：版本/构建、设备、Android、Root（已安装/未检测到）、LSPosed（已连接/未确认）。
2. **外观**：三档主题，即时生效。
3. **配置管理**：备份（含密钥）、还原、导出（脱敏）、分享（脱敏）、运行时导入、损坏恢复。
4. **诊断与日志**：日志（错误数）、权限与诊断、服务状态、复制诊断信息、清空本机日志。
5. **关于**：关于、许可、致谢、更新、作者/GitHub、免责。
6. **危险区**：折叠；0.14 只做停用全部。

**验收**

- [ ] 不显示账号/头像；副标题“本机设置”。
- [ ] 备份含密钥必须确认；脱敏导出不能还原。
- [ ] Root/LSPosed 不撒谎：无标准 API 显示“未确认”。

## 11. 配置管理 ConfigManage

| 行 | 风险 | 交互 |
| --- | --- | --- |
| 备份（含密钥） | 高 | 确认“明文 API Key/Token”；SAF 导出 |
| 还原配置 | 高 | SAF 选择；校验失败不覆盖；脱敏文件拒绝 |
| 导出（脱敏） | 低 | 分享/排障；不能还原 |
| 分享（脱敏） | 中 | FileProvider；提示可能被转发 |
| 从运行中小爱导入 | 中 | 需要小爱/控制面；导入后仍需保存 |
| 损坏恢复 | 高 | 仅在只读时出现；恢复/重建；原文件含密钥 |

## 12. 诊断与权限 Diagnostics

**行**：日志、通知权限、精确闹钟、全屏通知、电池优化、自启动、LSPosed、Root、Shizuku、服务状态、复制诊断信息、清空本机日志、兼容模式（只读）。

**规则**：无标准 API 显示“未确认”；Root 只显示“已安装/未检测到”，不显示“已授权”。

## 13. 日志 Logs

**内容**：计数 + 级别筛选 + 域筛选 + 跟随开关 + 列表 + 清空/分享。

**三种空态**：等待小爱上报 / 还没有日志 / 筛选无结果。

**行**：时间 Mono、级别胶囊、消息单行省略；错误 2dp 左竖条。

**深链**：`?level=E&focus=<seq>` 定位；无 seq 滚到底。
