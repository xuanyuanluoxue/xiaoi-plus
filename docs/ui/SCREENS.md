## 1. 首页 Home

**目的**：一屏回答“哪里不对、下一步点哪”。不做配置。

**区块顺序**

1. **状态总览**：四维徽章、Hero 标题/副行、最近上报、主按钮。
2. **快捷条**：校验模型 / 切换模型（只导航）/ 超级岛。
3. **待处理**：最多 3 条 issue；0 条显示“一切正常”。
4. **双域入口**：小爱卡、接入卡、能力清单文字入口。
5. **运行概况**：今日三方/官方、8771 端口与绑定、设备操作状态；问题 ≥2 时默认折叠。
6. **最近活动**：最近 3 条语义事件；查看全部 → Logs。

**数据**

```text
StateModel.resolveConfig / resolveApplied / resolveRuntime
StatusCache.probe（D2）
BridgeStatus.get()
AgentRuntime.snapshot()
PermissionProbe
IssueResolver
ActivityFeed.last(3)
BridgeClient.stats(port, token, 1)
```

**状态**：未配置、已暂停、校验中、端点可用但运行未确认、已确认、端点错误、小爱未连接、设备操作未就绪、配置损坏、权限缺失。每种都要有 CTA；不能只换颜色。

**待处理规则**：MCP 关闭（`mcpEnabled=false`）时不提示令牌/通道；D3 等待/超时与设备操作故障的 CTA 指向 `Bridge`；D4 不一致指向 `Xiaoai`。

**禁止**：输入框、开关、保存、provider/model 选择、token/LAN/主题/备份。

**验收**

- [ ] 只有 D4 `IN_USE` 显示“已确认”。
- [ ] 统计离线显示“—”，不显示 0。
- [ ] 8771 与设备操作分开判定；小爱未运行不把设备操作判死。
- [ ] 待处理 0 条不显示空卡。
- [ ] 快捷条只有一个校验入口；执行中禁用。
- [ ] 首屏无配置控件。

## 2. 小爱 Xiaoai

**目的**：回答“小爱现在用什么、是否在生效、下一步怎么变强”。

**区块**

1. **状态卡**：Hero + 主开关“启用第三方模型”（即时保存）。
2. **当前模型卡**：服务商/模型/端点 host/密钥是否设置；“管理模型”。
3. **运行态卡**：D3/D4、运行模型 vs 文件模型、最后上报；“重新通知”。
4. **增强能力**：系统提示词、记忆为可点入口；工具注入、技能包、语音与路由仍是只读占位。
5. **诊断入口**：最近错误 1 行 → Logs。

**状态**：未配置、配置损坏（开关禁用）、小爱未连接、超时、运行态不一致。

**验收**

- [ ] 主开关即时保存；失败回滚 + Snackbar。
- [ ] 关闭文案“配置全部保留”。
- [ ] 提示词、记忆可进入；其余 3 项只显示“规划中”，不可点击出假功能。

## 3. 模型与服务商 Model

**目的**：服务商/模型/端点/密钥的唯一可编辑表单。

**区块**：服务商 chips + 管理；模型 chips + 添加；端点；密钥（掩码）；校验/保存/取消。

**校验**：URL `http(s)://`；模型 ID 非空；密钥非空才可启用；同名去重；删除当前项自动切换。

**状态**：无服务商、无模型、URL 非法、密钥空、保存失败、文件冲突、配置只读。

**保存**：显式保存；失败保留草稿；成功后 `pop()` + Snackbar “已保存，等待小爱应用”。

**验收**

- [ ] 校验只更新 D2，不改 D4。
- [ ] 删除服务商确认说明连带删除模型/密钥。
- [ ] 配置损坏时输入禁用、保存阻止。

## 4. 接入 Access

**目的**：回答“谁可以连进来、连的是哪个通道、安不安全”。

**区块**

1. **外部接入总开关**：允许外部 AI 接入（即 `mcpEnabled`）。
2. **两个接口**：小爱任务、设备操作各一张卡（同一端口），显示状态/端口/绑定/局域网。
3. **令牌与安全**：是否设置、强度、小爱任务监听、设备操作监听。
4. **入口**：接口状态、令牌与局域网、连接信息、能力清单、工具清单、权限。
5. **停用全部**：在「我的 › 危险区」；接入页不放危险动作。

**事实约束**：设备操作没有独立开关，跟随 `mcpEnabled` + token，与 8771 同端口。

**验收**

- [ ] 小爱任务与设备操作状态分开；小爱未运行不影响设备操作判断。
- [ ] 弱令牌 + LAN 显示“已回退仅本机”。
- [ ] 复制提示“含令牌，勿外传”。
- [ ] 「我的 › 危险区」的停用全部列出四项影响；执行后首页/接入同步（接入页无危险动作）。

## 5. 端口与服务 Bridge（只读）

**内容**：小爱任务（状态/监听端口/实际绑定/局域网/最后连接/最后上报/已加载版本/运行模型）；设备操作（状态/监听端口/实际绑定/局域网/启动时间/最后错误/动作数/状态来源）；复制 URL、查看日志。整页只读，**没有重启或停止按钮**（保存配置触发重绑）。

**状态**：小爱任务等待上报/超时；设备操作未确认/启动失败；分开显示。

---

## 6. 令牌与局域网 Token

**内容**：令牌掩码/显示/生成/复制；8771 LAN；强度提示；保存/取消。设备操作与 8771 同端口，局域网、令牌一起跟随，不单列开关。

**确认文案**：

- “同一 Wi-Fi 下的设备都能访问 MCP 接口。公共 Wi-Fi / 公司网络建议保持关闭。”
- “局域网必须使用 32 位十六进制令牌；不足 32 位会自动回退仅本机。”
- “生成新令牌会让旧 MCP 客户端立即 401。”

**验收**

- [ ] 保存后设备操作接口重新绑定；小爱任务接口由小爱重新加载配置。
- [ ] 弱令牌不显示“局域网已开启”，显示实际绑定。

## 9. 我的 Me

**区块**

1. **本机与版本**：版本/构建、设备、Android、Root（已安装/未检测到）、LSPosed（已连接/未确认）。
2. **外观**：三档主题，即时生效。
3. **配置管理**：备份（含密钥）、还原、导出（脱敏）、分享（脱敏）、运行时导入、损坏恢复。
4. **诊断与日志**：日志（错误数）、权限与诊断、服务状态、复制诊断信息、清空本机日志。
5. **关于**：关于、许可、致谢、更新、作者/GitHub、赞助支持、免责。
6. **危险区**：折叠；只做「停用全部对外能力」。

**验收**

- [ ] 不显示账号/头像；副标题“本机设置”。
- [ ] 备份含密钥必须确认；脱敏导出不能还原。
- [ ] Root/LSPosed 不撒谎：无标准 API 显示“未确认”。

## 11. 配置管理 ConfigManage

| 行 | 风险 | 交互 |
| --- | --- | --- |
| 备份（含密钥） | 高 | 确认“明文 API Key/Token”；SAF 导出 |
| 还原配置 | 高 | SAF 选择；校验失败不覆盖；脱敏文件拒绝 |
| 导出（脱敏） | 低 | 分享/排障；不能还原 |
| 分享（脱敏） | 中 | FileProvider；提示可能被转发 |
| 从运行中小爱导入 | 中 | 需要小爱上报；导入后仍需保存 |
| 损坏恢复 | 高 | 仅在只读时出现；恢复/重建；原文件含密钥 |

## 13. 日志 Logs

**内容**：计数（`已显示 / 全部` 条，合并视图）＋ 级别筛选 ＋ 来源筛选 ＋ 进程筛选 ＋ 跟随最新 ＋ 列表；顶栏是清空与导出。

- **级别**：全部 / 信息 / 警告 / 错误 / 调试。
- **来源**：全部 / 小爱任务 / 设备操作 / 接口（按结构化 `tag` 判定，不猜正文前缀）。
- **进程**：全部进程，或某个已知进程的短名。
- **环境自检**：导出前先给出结论（正常 / 未装载 / 不兼容 / 尚未测到）与采集面计数。
- **导出**：ZIP 内含 `meta.txt` / `logs.txt` / `logs.json`，可选时间范围、级别、进程；导出的是整份合并视图，不受屏幕筛选影响。

**四种空态**：档位为关闭 / 等待小爱上报 / 还没有日志 / 筛选无结果。

**行**：时间 Mono、级别胶囊、消息单行省略；错误 2dp 左竖条。

**深链**：`?level=E&focus=<seq>` 定位；无 seq 滚到底。
